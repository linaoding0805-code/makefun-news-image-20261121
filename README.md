# makefun-news-image-20261121

One image that sums up the world's news of Saturday 21 November 2026, built
for the [make.fun](https://make.fun) competition
[news-image-20261121](https://make.fun/competitions/news-image-20261121).

The front page (`entry.png`, 1024 x 1024) leads with the Russian double-tap
missile strike on Kryvyi Rih, and carries the Russian missiles that strayed
into Polish airspace, the capture of cartel boss "El Chapo Isidro" in Mexico,
and Iran's claimed strikes on US positions in Bahrain, with the COP31 overtime
talks and the day's other stories below the fold.

## How it is made

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`/output/entry.png`. The page itself was composed in the build session from
four AI illustrations drawn for the day's reported events; the pictures are
labelled as illustrations on the page.
